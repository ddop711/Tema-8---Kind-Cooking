# Tema-8---Kind-Cooking

Introduktion til projektet: I vores projekt har vi valgt emnet Recipes fra DummyJSON API. Herfra henter vi udskriftsdata i JSON-format, som bliver vist dynamisk på vores hjemmeside. På siden vil brugeren se en liste med opskrifter, hvor hver opskrift bliver præsenteret som et card. Når man klikker på et card, kommer man videre til en side med flere detaljer om den enkelte opskrift. Derudover vil brugeren kunne filtrere opskrifter efter forskellige kategorier, så det bliver nemmere at finde relevante retter.

## Projektstruktur:

Billeder:
Vi har valgt at lave en mappe, som hedder, “Dishcard.webp”, hvor vi har det billede som vi bruger på vores "share_your_own_recipes" side. Udover den, så har vi også en anden mappe, der hedder, “logo_and_icons”, hvor vi har billederne af vores logo og de to ikoner, som indikerer sværhedsgraden af en ret på vores hjemmeside, liggende som webp’er.  
Fonte:
Vi har lagt vores font-families inde i generel.css’en. Fontene er hentet fra Google fonts.
Boilerplates:
Vi linker til de filer, som bruges på tværs af projektet oppe i head af vores HTML filer.

## Navngivning:

For at holde styr på filer har korsponderer til hinanden. For eksempel hedder CSS filen der tilhører HTML siden Share_your_own_recipes, recipes.css.

## Link til scripts:

Links til scripts ligger vi i bunden af vores HTML sider under body.

## Git branches:

Vi har navngivet de branches vi arbejder på navnet på vores main sider. Nogle af os har tagget dem med et nummer i slutningen så det er synligt hvilken update det er, mens andre har brugt nye navne der tydligøre hvilken del af siden der er blevet arbejdet på.
